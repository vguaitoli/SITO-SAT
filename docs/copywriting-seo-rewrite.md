# Riscrittura copywriting + SEO — Sardegna Trail Avventura

**Cos'è questo file.** Una riscrittura completa di tutti i testi editoriali del sito, pensata come la scriverebbe un copywriter umano: frasi vive, ritmo naturale, un beneficio concreto per riga. Ogni sezione integra le parole chiave più cercate su Google per il settore (*tour fuoristrada Sardegna, tour enduro Sardegna, tour maxienduro Sardegna, tour Sardegna, tour maxienduro, tour 4x4*, e le varianti per quad, SSV, e-bike, noleggio) senza mai forzarle: compaiono dove un utente le scriverebbe davvero, mai ripetute meccanicamente nella stessa sezione.

**Regola che ho seguito ovunque:** zero dati inventati. Nessun itinerario, prezzo, data, recensione o luogo che non fosse già presente nel sito. Ho riscritto *come si dice*, mai *cosa* — durate, km, livelli, tappe reali restano quelli già confermati nel progetto (TourDetails / tina-snapshot.json / categorie.js).

**Come si usa.** Questo è un documento di lavoro, non ancora applicato al sito. Ogni blocco riporta: testo attuale (per confronto rapido) → testo riscritto → note. Alla fine trovi una checklist di file da aggiornare quando deciderai di procedere.
